# Yixiu 1.9 sharing, reminders, widgets, and iPad submission

Date: 2026-09-05 Asia/Shanghai

## Release contents

Version 1.9 build 21 adds:

- Scene sharing as a 1080 × 1350 image with a QR code in the lower-right, using the standard iOS share sheet.
- An opt-in local daily quiet reminder in My Yixiu, defaulting to 21:30. Notification permission is requested only when the user enables the reminder.
- Home Screen and Lock Screen “One-Minute Pause” widgets.
- Universal iPad support in portrait and landscape.

The production archive uses normal StoreKit entitlement verification. It does not contain the internal `YIXIU_INTERNAL_PLUS` preview condition or the internal all-sounds-unlocked message.
