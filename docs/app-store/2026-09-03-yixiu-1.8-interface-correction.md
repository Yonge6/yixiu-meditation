# Yixiu 1.8 Interface Correction

Date: 2026-09-03 Asia/Shanghai

## Root cause

The accepted 1.6 interface changes lived on `codex/yixiu-bright-scenes-20260830`, but that branch was not merged into `main`. Version 1.7 build 19 was later created from `main` while adding the Smart Stack extension, so it carried the older iPhone interface even though the Smart Stack implementation itself did not remove those features.

The affected interface elements were the English-first launch state, the Sounds header language/share controls, the native SwiftUI tab bar, the premium faceted-gem badge, and five brighter meditation scene artworks.

## Public-state evidence

Apple's public Lookup response reported version `1.7`, bundle ID `com.health.yixiu`, and release timestamp `2026-09-02T19:33:19Z` (`2026-09-03 03:33:19` Asia/Shanghai).

An attempted corrective `1.7 (20)` upload was rejected because the 1.7 pre-release train was already closed and 1.7 was the approved version. The corrective release therefore advanced to `1.8 (20)`.

## Correction

- Restored the exact final 1.6 iPhone source and five revised scene assets on top of the merged Smart Stack code.
- Preserved the one-minute Control, Live Activity, and Smart Stack extension.
- Advanced both the host app and widget extension to `1.8 (20)`.
- Merged the correction through GitHub pull request #214.
