# YouTube channel App Store link — design

## Context

WonderElian's existing Yixiu Community posts keep their attributed H5 and App Store destinations, but YouTube renders those external URLs as plain text because advanced external links would require sensitive identity verification. The posts now give mobile visitors a verified path through the clickable WonderElian author and the channel's existing `Yixiu` profile link. That first link must remain unchanged because the public posts name it directly and it routes several intents through the official H5.

Apple campaign outcomes from YouTube remain `null`; a new link is only a measurable path, not evidence of a visit or download.

## Options

1. **Add a second channel link for the App Store.** Preserve the first `Yixiu` H5 link and add `Yixiu for iPhone` with an Apple partner/campaign URL. This creates a persistent, clickable download path for existing and future channel visitors without a new post or video.
2. Replace or retarget the first `Yixiu` link. This could improve one landing intent but would contradict existing Community instructions and weaken the current multi-intent H5 path.
3. Publish another Community post. This would repeat the same-day cadence and its external URL would still be plain text.

Option 1 is selected because it adds the shortest direct App Store path while preserving the already verified H5 funnel.

## Exact change

- Existing first link: preserve its current label, position and URL.
- New label: `Yixiu for iPhone`
- New destination: `https://apps.apple.com/us/app/yixiu-white-noise-sleep/id1461182261?pt=120014121&ct=yixiu_youtube_channel_20260831&mt=8`
- Do not change channel description, handle, videos, posts, playlists or unrelated links.

## Acceptance

- Authenticated desktop Chrome confirms the correct WonderElian channel before editing.
- The edit UI shows the existing `Yixiu` H5 link unchanged and a second `Yixiu for iPhone` link with the exact campaign token.
- Save/publish completes without identity material, password, OTP or legal acceptance.
- A fresh public channel readback exposes both clickable links and resolves the App Store link to Yixiu's official listing.
- No new upload or Community post is created, and no other product is touched.
- Link clicks, downloads, trials, payments, subscriptions, IAP and revenue remain `null` until authoritative platform evidence appears.
