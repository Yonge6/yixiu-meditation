# 一休日常 / Quiet Journal

User authorized an H5 column in the drawer and selective synchronization of suitable social content. Retain the three bottom tabs and existing player; add a book-shaped journal entry in the player header and a row in Me. Both open a dedicated reading drawer using the existing accessible drawer shell. Never expose the retired settings drawer or alter Apple membership rules.

Ship three original bilingual practical notes (rest, focus, one-minute pause) with matching Free listening/practice actions. Browsing and reading in the drawer must preserve current playback. Article return goes to its list, close restores focus, Escape closes. Standalone bilingual index/article pages provide shareable URLs, canonical/hreflang, article metadata and sitemap discovery.

Source of truth: yixiu-prototype/src/data/quiet-journal.json. A deterministic build-journal.mjs generates static reading pages. New content uses a stable slug, publication date, verified free scene, image, bilingual titles/summary/sections and optional originating social content IDs. Do not mechanically clone daily posts.

Update the existing daily automation, keeping social frequency, schedule, target task and unrelated monitoring intact. Select at most one genuinely useful new article per day; skip H5 when neither item adds lasting value, without reducing social quotas. H5 completion requires the public article and drawer readback, not a file or Git push.

Validation: runtime lock, TypeScript/build, existing Sites suite, focused browser tests for drawer navigation/audio continuity, bilingual static routes and attribution links; local and production mobile/desktop visual inspection. Deploy only the Yixiu site from latest main with a pinned release, backup and public acceptance.
