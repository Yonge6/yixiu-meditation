Replace the generic opening with a short product-first block: a direct attributed link to the Yixiu dark-screen rain player, one sentence describing the actual web behavior, and the official App Store link. Retain the original session description, usage guidance, disclosure and hashtags below it.

This is the strongest option because it uses the existing video's current search/watch surface, moves the product path into the first visible description lines, and creates a distinct `youtube / organic_description` attribution row if a visitor clicks. The existing `youtube / organic_video` URL is replaced rather than duplicated.

The existing comment already contains direct Yixiu H5 and App Store links. Editing it would provide little new coverage, and pinning the only comment does not solve the missing video-description path. It remains useful as a secondary route and should be preserved.

### 3. Upload or publish another YouTube item
