# 一休 GEO / SEO / ASO 执行设计

用户已授权继续搜索增长，并把合适内容放入现有抽屉栏目。沿用一休日常，无需另建内容系统。

先修订已过时的产品信息，再基于真实查询优化已有页面，最后将独立实用指南加入栏目。批量增加同义页面会分散同一搜索意图；全量重写商店名称则缺少足够对照数据。本次选择统一事实、现有睡眠比较页优化、双语使用指南和商店推广文本更新。

数据流：真实 Search Console / 公开 App Store / 当前产品 → 已核验内容 JSON → 抽屉及静态双语页 → canonical / hreflang / Article / sitemap / llms。引用链接、自然标题和完整正文同时对用户可见。llms 是补充目录，不当作 AI 收录证明。关键词方案保存在运营文档，不能把内部优化术语发进用户栏目。

验收：生产页面、商店保存字段、Google 站点地图受理各自回读；未获得的索引、AI 引用、下载与付费数据保留 null。构建、相关浏览器与站点测试通过后沿用固定哈希和备份的阿里云发布流程。
