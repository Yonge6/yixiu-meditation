# Underwater White Noise Pinterest Video Design

## Decision

The Underwater White Noise sleep intent already has a live Yixiu landing page and a publicly verified static Pinterest Pin, but no video Pin. The existing Thunder, Morning Birds, Forest Sleep and Waterfall video assets are already published, so repeating one of them would add duplicate inventory. A distinct underwater-white-noise video is the next useful gap in the authorized Yixiu Pinterest board.

Three approaches were considered:

1. Republish the existing static image. This is fastest but creates a near duplicate with no new native format.
2. Create another search landing page. Search Console exposes no new query row, and the matching page already exists.
3. Create a Pinterest-native 20-second video from the existing Yixiu underwater image and licensed recording. This is selected because it adds a new distribution format while preserving one exact destination and measurable attribution.

## Creative

The video is 1080×1920, H.264/AAC, 20 seconds. It uses the existing Yixiu `underwater-echo.png` image with a restrained continuous push-in and the existing `underwater-white-noise.m4a` recording. It contains three legible text beats:

- `UNDERWATER WHITE NOISE`
- `NO MUSIC · NO TALKING`
- `LISTEN FREE / TAP VISIT SITE`

The Yixiu name remains visible, and the final frame keeps the direct action on screen long enough to read. The visual is AI-modified, so Pinterest's AI-modified disclosure must be enabled. No sleep guarantee, medical claim, rating, review count or fabricated outcome appears.

## Publication

Publish only from the logged-in WonderElian Pinterest account to the existing `Yixiu: Nature Sounds & Sleep` board. Use this destination:

`https://yixiu.wonderelian.com/underwater-white-noise-for-sleep/?utm_source=pinterest&utm_medium=organic_video&utm_campaign=sleep_sounds&utm_content=underwater_white_noise_sleep_video_pin_02`

The title and description distinguish the video from the existing static Pin and accurately describe the real Yixiu recording. Similar-product recommendations remain disabled where the control is available. Do not add collaborators, product tags, paid promotion, another board, another product, or a cross-post.

## Acceptance

Before upload, verify dimensions, duration, codecs, audio presence, file size, SHA-256 and representative frames from the opening, middle and final CTA. After publication, require a permanent public Pin URL, correct account and board, visible 20-second playback, AI-modified disclosure, exact title/description/destination/alt text, and HTTP 200 for both Pin and destination. Pinterest publication proves a live attributable acquisition surface only; H5 UV and App downloads remain governed by GA4 and Apple official data.
