# 一休 H5 多尺寸响应式设计

## 目标

让同一套 H5 在手机、平板、小屏笔记本、常规桌面与超宽屏上都保持沉浸感，并以现有 iPhone App 的视觉与交互为基准。

## 设计方向

- 手机端保留现有全屏播放器，不改变熟悉的操作位置。
- 平板及桌面端把自然场景扩展到整个浏览器视口，播放器内容保持在舒适阅读宽度内。
- 桌面底部导航改为悬浮式玻璃导航坞，不把整条屏幕切成一块深色横栏。
- 声音库在桌面端改为右侧浮层，场景卡片使用三列；平板使用居中大面板。
- “静心”和“我的”使用独立内容宽度上限，避免宽屏拉伸，同时支持纵向滚动。
- 二级页面、弹窗、抽屉统一限制最大宽度，保证可读性与操作距离。

## 响应式区间

- `< 720px`：现有手机布局。
- `720px–1099px`：平板与小屏设备，内容居中、导航悬浮、声音库放大。
- `>= 1100px`：桌面布局，全屏场景、宽松标题与控制区、右侧声音库。
- `>= 1680px`：超宽屏只增加安全留白和场景尺度，不继续放大控件。

## 验收

- 390×844、768×1024、1024×768、1440×900、1920×1080 均无横向溢出。
- 手机端主要控件位置不回退。
- 桌面端背景覆盖整个视口，主要操作无需把鼠标移动到屏幕边缘。
- 声音库、静心、“我的”和二级页均可完整滚动与关闭。
