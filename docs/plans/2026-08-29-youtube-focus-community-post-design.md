# Yixiu YouTube Focus Community Post Design

Date: 2026-08-29

## Objective

Add one isolated, measurable Focus acquisition surface on the official WonderElian YouTube channel without uploading a video, changing the mixed-product channel profile, enabling a homepage that alters other-product presentation, or making unsupported claims.

## Live-state decision

The public channel currently has no visible Home tab; it opens on Videos and exposes separate Shorts, Playlists and Posts tabs. YouTube Studio's Home-tab editor showed that enabling Home would automatically surface all channel videos, all Shorts, four created playlists and the existing post. Because that would change the presentation of Style Atlas and other non-Yixiu content, the Home tab remains disabled.

Options considered:

1. Enable and customize the channel Home tab. Rejected because the initial enablement automatically changes mixed-product channel presentation.
2. Add a channel profile link. Rejected because it would apply a Yixiu referral across the entire mixed-product channel profile.
3. Publish one isolated Focus community post. Selected because the existing post is Sleep-oriented, the new post is additive, attributable and limited to Yixiu.

## Publishing constraints

- Publish from WonderElian as a text post only.
- Do not attach an image, poll, quiz, video upload or another product.
- Do not edit or delete the existing Sleep post.
- Do not enable the channel Home tab or add a profile link.
- Keep the exact H5 `youtube / organic_social / focus_sounds / community_focus_playlist_01` attribution.

## Verification

- Require a permanent public post URL.
- Require authenticated public DOM readback for WonderElian, exact copy, H5 link, Focus playlist link and all three hashtags.
- Require the public post and both linked destinations to return HTTP 200.
- Use logged-out HTML or another public readback to prove the post is not merely a private draft where available.
- Record a fresh exact-hostname GA4 source/campaign/content report. Do not attribute a visit unless `community_focus_playlist_01` appears.

## Completion boundary

The post completes one distribution action only. The long-term goal remains active until a completed Beijing natural day proves at least 100 exact-hostname active users and Apple official analytics proves downloads. Unknown trial, paid, subscription, in-app-purchase and revenue values remain `null`.
